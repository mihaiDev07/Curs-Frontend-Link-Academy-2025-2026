# WebSocket Chat Application

O aplicație de chat în timp real construită cu Node.js (backend), WebSocket și Axios (pentru comunicație) și HTML/CSS/JavaScript (frontend).

## Caracteristici

✅ **Chat în timp real** - Mesajele sunt transmise instant folosind WebSocket  
✅ **Fără autentificare** - Doar adaugă un nume și începe să chatiezi  
✅ **Multi-user** - Urmărire simultaneă a utilizatorilor în mai multe browsere  
✅ **Editare mesaje** - Utilizatorul poate edita mesajele proprii  
✅ **Ștergere mesaje** - Utilizatorul poate șterge mesajele proprii  
✅ **Interfață modernă** - Design responsiv și atractiv  
✅ **Sincronizare în timp real** - Toate modificările sunt vizibile instant în toate browserele

## Instalare și Rulare

### 1. Instalare Dependențe Backend

```bash
cd backend
npm install
```

### 2. Pornire Server Backend

```bash
npm start
```

Serverul va rula pe `http://localhost:3000`

### 3. Deschidere Frontend

Deschide browserul și accesează: **http://localhost:3000**

## Testare cu Multipli Utilizatori

Pentru a simula 3 utilizatori diferiți, deschide 3 browsere diferite:

1. **Chrome** - Deschide `http://localhost:3000` și introdu un nume (ex: "Andrei")
2. **Safari** - Deschide `http://localhost:3000` și introdu un alt nume (ex: "Maria")  
3. **Firefox** - Deschide `http://localhost:3000` și introdu un al treilea nume (ex: "Ioan")

Toate mesajele din orice browser vor fi vizibile instant în celelalte browsere!

## Funcționalități Detallate

### Trimitere Mesaj

1. Introdu numele tău în câmpul "Enter your name"
2. Scrie mesajul în câmpul "Type a message"
3. Apasă butonul "Send Message" sau Enter

### Editare Mesaj

1. Hover peste mesajul propriu (doar proprii mesaje pot fi editate)
2. Apasă butonul "✏️ Edit"
3. Modifică textul în modal
4. Apasă "Save Changes"

### Ștergere Mesaj

1. Hover peste mesajul propriu (doar proprii mesaje pot fi șterse)
2. Apasă butonul "🗑️ Delete"
3. Confiră ștergerea

## Comunicare Frontend-Backend

### WebSocket
- **Conexiune**: `ws://localhost:3000`
- **Tipuri mesaje**: `init`, `new_message`, `edit_message`, `delete_message`
- **Folosit pentru**: Sincronizarea în timp real între toți clienții

### Axios (HTTP REST API)
- `GET /api/messages` - Obține toate mesajele
- `POST /api/messages` - Adaugă un mesaj nou
- `PUT /api/messages/:id` - Editează un mesaj
- `DELETE /api/messages/:id` - Șterge un mesaj

## Notă Privind Stocarea

Mesajele sunt stocate **în memorie** (RAM). Aceasta înseamnă că mesajele vor fi șterse atunci când serverul este oprit. Pentru stocarea persistentă, poți integra o bază de date cum ar fi MongoDB, MySQL, etc.

## Troubleshooting

**Problemă**: "Cannot GET /"
- **Soluție**: Asigură-te că serverul rulează cu `npm start`

**Problemă**: WebSocket nu se conectează
- **Soluție**: Verifică dacă port-ul 3000 nu este ocupat

**Problemă**: CORS error
- **Soluție**: CORS-ul este deja configurat în server.js
