# 🛍️ Final Project — Vellora Shop

**Vellora Shop** is my final project for the Link Academy Frontend Development program: a full-stack e-commerce application built with React, TypeScript, Node.js, Express, and SQLite.

The application includes a responsive product catalog, authentication, shopping cart and checkout functionality, order management, user profiles, and role-based administration.

- 🌐 **Live application:** [https://vellorashop.vercel.app](https://vellorashop.vercel.app)
- 💻 **Complete source code and documentation:** [github.com/mihaiDev07/Vellora-Shop](https://github.com/mihaiDev07/Vellora-Shop)
- ⚙️ **Backend API:** Deployed on Render

The complete project is maintained in its dedicated repository. This folder connects the course archive to the final submitted application without duplicating its source code.
